Large Language Models (LLMs) are fundamentally stateless during inference. This characteristic means they do not inherently retain information or context from previous interactions or turns in a conversation.

That is why, for any new input or query, an LLM processes it independently, basically without automatically remembering prior dialogue. This stateless nature presents challenges, particularly when building conversational AI or agents that require continuity, such as maintaining user preferences or historical discussion. The context window, which is the limited span of text an LLM can consider at one time, further complicates this, as past interactions quickly fall out of scope.

To address these limitations and enable more sophisticated, context-aware applications, the concept of "memory" is introduced into LLM-based systems. Memory allows these systems to recall and utilize past information, mimicking human cognitive processes.

Working with long-term memory in AI agents typically involves several key steps:
-> Creation: This initial phase captures relevant information from user interactions, model outputs, or external data sources. For instance, user preferences or key facts extracted from a conversation are identified.
-> Storage: Once created, this information is then stored persistently outside the LLM, often in a vector database or a specialized knowledge base. This allows for recall across sessions and beyond the current context window.
-> Retrieval: When a new query arrives, the system intelligently retrieves the most relevant pieces of stored memory. Different retrieval strategies, such as semantic search or keyword matching, can be employed.
-> Injection: Finally, the retrieved memory is injected back into the LLM's prompt, providing it with the necessary context to generate a coherent and informed response.

This approach facilitates persistent memory, which essentially connects the short-term context of the LLM with a durable external database. Several frameworks and systems are emerging to manage this, such as LangMem, Mem0, and Supermemory, each offering different abstractions and optimizations for building memory-aware agents.
